# 소화 스티커 탐험 — 소화계와 소화효소 수업 자료

중학교 2학년 과학 **Ⅵ. 동물과 에너지 — 1. 에너지원의 흡수와 운반** 중 「영양소를 소화하는 소화계」, 「소화효소가 작용하는 소화 과정」을 스티커 붙이기 활동으로 익히는 HTML 자료입니다.
설치 없이 브라우저에서 바로 열 수 있고, 휴대폰·태블릿·크롬북에서도 사용할 수 있습니다.

## 구성 (약 45분)

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 생각 열기 | 5분 | 핵심 질문: "주먹밥과 포도당 사탕은 어떤 과정을 거쳐 세포에 공급될까?", 밥을 오래 씹으면 단맛이 나는 까닭 |
| ② 스티커 활동 1 | 10분 | 소화계 그림에 기관 이름 10개 붙이기 → 소화관·소화샘 구분, 기관별 기능 확인, 🍙 급식 여행 애니메이션 |
| ③ 스티커 활동 2 | 12분 | 소화효소 지도: 입·위·작은창자에서 녹말·단백질·지방을 분해하는 소화효소, ✕(소화 안 됨), 쓸개즙(도우미), 최종 소화 산물 붙이기 |
| ④ 스티커 활동 3 | 6분 | 작은창자 융털 그림에 융털·암죽관·모세혈관 붙이기 → 흡수 이야기 카드 열림 |
| ⑤ 생활 속 소화 | 5분 | 뒤집기 카드 8장: 식혜와 엿기름, 고기 양념의 파인애플, 삼겹살과 쓸개즙, 위액의 염산, 소화제 등 |
| ⑥ 확인 문제 | 5분 | 7문항 자기 점검 (교과서 개념 확인·침 실험 포함) |
| ⑦ 정리 | 2분 | 핵심 질문에 내 말로 답하고 교과서 정리와 비교 |

## 특징

- 스티커는 **끌어서 놓기** 또는 **눌러서 고른 뒤 빈칸 누르기** 두 가지 방법으로 붙일 수 있습니다 (터치 화면 지원).
- 틀린 칸에 붙이면 스티커가 돌아가고, 그 스티커에 맞는 힌트가 나옵니다.
- 활동 기록은 각자의 브라우저에만 저장되며 서버로 전송되지 않습니다. 각 활동의 "다시 하기"로 초기화할 수 있습니다.

## 파일

- `index.html` — 수업 자료 본문
- `images/` — 교과서 그림 (비상교육 중학교 과학 2, 그림 6-1, 6-2, 6-3)
